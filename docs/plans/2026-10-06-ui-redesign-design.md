# Takeoff UI 与 UX 重设计 · 2026-10-06

## 最终方向

依据用户提供的布局截图：顶部品牌，城市名与坐标在上方，单个机窗居中，
城市、地标和操作在下方。页面使用深色背景，配套暖白文字与黄铜色细节。
早期米色方向已被用户的后续指示替代；以该参考布局与最新深色要求为准。
每座城市分别生成一张插画，替换网页中的实景照片。

## 页面与操作

- 单窗视觉：城市名、坐标、机窗、中文城市与地标、目的地入口、播放控制
  自上而下排列。手机保留同一结构，横屏压缩间距。
- 设置收起：停留时间、声音、路线与进度、沉浸模式放入“靠窗偏好”。打开
  设置继续漫游；关闭后恢复入口焦点。环境音偏好只改变开关，声音随漫游播放。
- 漫游：上一站、播放／暂停、下一站；支持键盘。遮光板向上轻推关闭，换城
  后向下打开，保持参考场景的操作方向。默认每站 8 秒，可选 5／12 秒。
- 目的地：六洲筛选、中文／英文／地标搜索、结果漫游与随机选择；空结果可
  恢复全量目录。首页保留探索与随机入口。
- 资料：城市、地标、坐标来源可查阅；明确标示 AI 城市插画和艺术化视角。
  原始研究照片与原版影片素材的作者和许可保留在资料页展开项与开源记录中。

## 插画

使用 OpenAI 内置 imagegen，每个城市一次独立生成，以已核对的城市和地标
资料为依据，统一手绘水粉旅行插画风格。每张为纵向构图，地标位于画面中央，
适应圆角机窗的比例裁切。保存完整提示词、生成标识、原始输出校验值，以及
WebP 文件的尺寸、字节数和 SHA-256。仅做格式压缩，保留原构图与像素尺寸。
原始 PNG 保存在本地 `output/imagegen/originals/`；网站使用本地 WebP 文件。

## 动效与状态

照片／插画加载失败恢复当前画面并给出重试提示。快速连续切换服从最新意图；
打开目录暂停漫游；减少动态效果偏好禁用位移与自动启动。沉浸模式扩大机窗，
保留退出操作。机窗解码缓存最多保留 8 张，限制长时间移动端漫游的内存占用。

## 技术与验收

使用原生 HTML、CSS、JavaScript 与 Cloudflare Static Assets。原生 dialog
管理模态焦点，VisualViewport 管理软键盘后的可见区域。字体本地托管，保留
Newsreader 与 Manrope 的 OFL 许可。不增加远程字体、图片请求或追踪。

参考：[MDN dialog](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog)、
[VisualViewport](https://developer.mozilla.org/en-US/docs/Web/API/VisualViewport)、
[prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)。

验收包括 120 张插画的独立性、校验值与浏览器解码；搜索、路线、随机、触屏
上推遮板、快速切换、停留时间、暂停、音频、模态焦点、减少动态效果，14 种
手机／平板视口，360 次城市标题边界检查，以及字体与颜色对比度。
本地验收完成后推送公开 GitHub 仓库，部署现有 Cloudflare 域名，并单独核验
HTTPS、线上交互、全部插画字节、版本与 CI。
